### 한정판 구매·티켓팅, 1초가 중요한 순간에

한정판 발매, 공연 티켓 예매, 수강 신청처럼 시작 시간을 기다리는 순간. 시간 확인용 창을 따로 띄우고 오갈 필요 없이 **사용하던 브라우저 위에서 바로 시간과 남은시간을 확인**할 수 있습니다. PC 없이 스마트폰 하나로 간편하게 준비하세요.

- **작은 시계, 편한 위치:** 화면 위에서 원하는 곳으로 드래그하세요.
- **목표시간까지 한눈에:** 빨간색 남은시간으로 얼마나 남았는지 확인하세요.
- **1분 전 미리 알림:** 알람음·진동·하이라이트를 원하는 대로 선택하세요.
- **자주 가는 곳은 한 번에:** 네이버 검색과 즐겨찾기로 사이트를 쉽게 선택하세요.
- **보고 있는 페이지에서 바로:** 브라우저의 공유 → 타임딜레이제로로 시계를 시작하세요. 네이버 단축 링크도 원래 사이트를 확인합니다.
- **내 눈에 편한 화면:** 여섯 가지 컬러, 다크·라이트 모드, 글자 크기와 불투명도를 조절하세요.
- **구형 기기는 가볍게:** 자동·경량 성능 모드로 화면 갱신 부담을 줄입니다.

### 설치·보안 안내

1. 위 **최신 APK 바로 다운로드**를 누릅니다.
2. 다운로드한 `time-delay-zero.apk` 파일을 엽니다.
3. **설치** 또는 **업데이트**를 누릅니다. 기존 앱은 삭제하지 마세요.

Android 8.0 이상 설치를 지원합니다. 구형 실기기 동작은 추가 확인이 필요하며 일부 Android Go·제조사 제한 기기는 오버레이를 사용할 수 없습니다. iPhone은 지원하지 않습니다.

**‘출처를 알 수 없는 앱 설치 / 이 출처 허용’** 안내가 나오면 휴대폰 설정에서 ‘출처를 알 수 없는 앱 설치’를 검색한 뒤, APK를 여는 **Chrome·삼성 인터넷·내 파일 등 해당 앱**을 선택해 허용하세요. 타임딜레이제로에 주는 권한이 아닙니다. 설치 후 같은 경로에서 다시 끄세요. [삼성 공식 설치 안내](https://www.samsung.com/us/support/troubleshoot/TSG10001914/)

**갤럭시 ‘보안 위험 자동 차단’** 때문에 차단됐다면, 공식 파일임을 확인한 사용자가 **설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단**에서 일시 해제할 수 있습니다. 설치 후 다시 켜주세요. 메뉴는 기종·Android/One UI에 따라 다릅니다. [삼성 공식 보안 위험 자동 차단 안내](https://www.samsung.com/us/support/answer/ANS10003636/)

**Google Play 프로텍트 검사 요청과 유해 앱 차단은 다릅니다.** 검사 요청은 검사를 진행하고 결과를 확인하세요. ‘유해 앱/기기 보호 차단’이면 경고를 무시하거나 보호 기능 전체를 끄지 말고 공식 파일·버전을 확인한 뒤 [개발자에게 차단 문구를 알려주세요](https://github.com/ZERO-hms/time-delay-zero/issues). 개발자는 오탐 검토를 요청할 수 있습니다. 특정 설정 변경으로 모든 차단이 해결되지는 않습니다. [Google 공식 안내](https://support.google.com/googleplay/answer/2812853?hl=ko)

회사·학교 관리 기기의 정책 제한은 관리자에게 문의하세요. 보안 설정은 사용자가 직접 변경하며 앱이 자동 해제하지 않습니다. 설치 후에도 **⚙ 설정 → 설치·권한 안내 다시 보기**에서 같은 안내를 확인할 수 있습니다.

### 설치 후 필요한 권한

- **다른 앱 위에 표시:** 브라우저 위에 시계를 띄우는 데 필요합니다. 허용하지 않으면 오버레이를 시작하지 않습니다.
- **알림:** 실행 중인 시계·목표시간·업데이트 알림에 사용합니다. 허용하지 않아도 시계는 쓸 수 있지만 시스템 알림을 받지 못할 수 있습니다.
- 인터넷 연결과 진동은 동기화·선택한 알림 기능에 사용합니다. 접근성·사용정보 접근·무선 디버깅을 요구하지 않습니다.

설치 출처 허용과 위 기능별 권한은 별개입니다. 소리·진동은 알람 볼륨·방해 금지 등 휴대폰 설정의 영향을 받습니다.

### 업데이트 내용도 앱에서 확인

**⚙ 설정 → 앱 업데이트**에서 현재 버전의 변경사항과 새 버전 내역을 확인할 수 있습니다. 공식 배포 주소가 기본 연결되어 있어 별도 입력이 필요 없습니다. 앱을 열 때와 백그라운드에서 약 6시간 간격으로 새 버전을 확인하며, **지금 업데이트 확인**도 지원합니다. 새 버전을 발견하면 상태표시줄과 알림창에 안내하고, 알림을 누르면 변경사항과 다운로드 화면이 열립니다. 다운로드 후 설치 확인은 직접 눌러주세요.

**설치 후 앱을 한 번 열고**, 설정 → 앱 업데이트 → **알림 허용·설정**에서 알림을 허용해주세요. **상태표시줄 테스트 알림 보내기**로 표시와 화면 연결을 확인할 수 있습니다. 이 버전 설치 후 올라오는 새 릴리스부터 백그라운드 알림을 받을 수 있습니다.

즉시 도착하는 푸시가 아닙니다. 절전·네트워크 상태에 따라 확인이 늦어질 수 있으며, 앱을 강제 종료했다면 다시 열어주세요. 실제 기기에서의 알림 표시와 절전 중 실행은 추가 확인이 필요합니다.

### 브라우저에서 공유로 시계 시작

1. Chrome·삼성 인터넷 등 사용하던 브라우저에서 시간을 확인할 사이트를 엽니다.
2. 브라우저의 **공유** 메뉴에서 **타임딜레이제로**를 선택합니다. 처음에는 공유 목록의 더보기에 있을 수 있습니다.
3. 해당 사이트로 시계를 시작하고 브라우저로 돌아갑니다. 시계가 이미 켜져 있으면 공유한 사이트로 다시 동기화합니다.

처음에 ‘다른 앱 위에 표시’ 권한이 없으면 안내 화면에서 **시계 표시 권한 허용**을 누르세요. 휴대폰 설정에서 허용한 뒤 돌아오면 이어서 시작합니다. 개발자 옵션·무선 디버깅·접근성 권한이나 별도 앱 설치는 필요하지 않습니다.

공유한 주소에서 도메인만 사용하며, HTTP 링크도 실제 시간 확인은 HTTPS로 연결합니다. 주소가 없거나 서로 다른 사이트가 여러 개 포함된 경우에는 기존 시계를 유지합니다. 네이버 단축 링크(naver.me)는 원래 HTTPS 주소를 확인한 뒤 시계를 시작합니다. 홈페이지 주소를 따로 찾을 필요 없이 원하는 페이지를 그대로 공유하세요. 네이버 검색결과를 공유하면 네이버 검색 도메인 기준이므로, 특정 쇼핑몰·예매 사이트의 시각을 확인하려면 해당 사이트 페이지를 열고 공유하세요. 브라우저에서 다른 사이트로 이동했을 때는 새 사이트를 다시 공유해야 합니다. 즐겨찾기·목표시간·오버레이 설정은 유지됩니다.

### 시간 정확도 안내

HTTP Date와 통신 왕복 시간을 이용한 추정 시각입니다. 응답은 보통 초 단위이며 밀리초는 보간한 표시입니다. CDN·캐시·통신 지연, 실제 예매 처리 서버 차이로 오차가 생길 수 있어 밀리초 정확도나 구매·예매 성공을 보장하지 않습니다. 브라우저의 현재 사이트를 자동 감지하지 않으므로 확인할 사이트를 앱에서 선택하거나 브라우저에서 공유해주세요. 알림은 앱 실행 상태와 휴대폰 설정의 영향을 받습니다.

### v1.00.3 변경사항과 검증

브라우저 공유로 시계를 시작하고, 실행 중에는 공유한 사이트로 전환할 수 있습니다. 네이버 단축 링크를 실제 사이트 주소로 풀지 못해 발생하던 동기화 실패를 수정했습니다. 주소 확인 실패 시 재시도 안내를 표시하며 기존 시계와 즐겨찾기·목표시간·오버레이 설정을 유지합니다. 앱 내부와 이 페이지의 설치·보안 안내도 보완했습니다. 메인 화면은 앱 아이콘·제목을 왼쪽에, 설정 톱니바퀴를 오른쪽에 배치했습니다.

단위 테스트 77개와 Android 15 에뮬레이터 통합 시나리오 10개를 통과했습니다. 실제 네이버 공유 링크의 주소 변환과 서버 시각 표시를 확인했습니다. Galaxy Z Fold7 및 각 브라우저의 실제 공유 메뉴 동작은 실기기에서 추가 확인이 필요합니다.
