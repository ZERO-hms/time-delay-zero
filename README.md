### 사이트마다 다른 서버 시각, 스마트폰에서 간편하게

타임딜레이제로는 **선택한 사이트의 서버 응답 시각을 주기적으로 동기화해 보여주는 앱**입니다. 휴대폰 시각과 사이트 서버 시각의 차이를 반영한 추정 시각을 작은 오버레이 시계로 확인하세요.

### 한정판 구매·티켓팅, 1초가 중요한 순간에

한정판 발매, 공연 티켓 예매, 수강 신청처럼 시작 시간을 기다리는 순간. 시간 확인용 창을 따로 띄우고 오갈 필요 없이 **사용하던 브라우저 위에서 바로 시간과 남은시간을 확인**할 수 있습니다. PC 없이 스마트폰 하나로 간편하게 준비하세요.

- **작은 시계, 편한 위치:** 화면 위에서 원하는 곳으로 드래그하세요.
- **목표시간까지 한눈에:** 빨간색 남은시간으로 얼마나 남았는지 확인하세요.
- **1분 전 미리 알림:** 알람음·진동·하이라이트를 원하는 대로 선택하세요.
- **자주 가는 곳은 한 번에:** 네이버 검색과 즐겨찾기로 사이트를 쉽게 선택하세요.
- **내 눈에 편한 화면:** 여섯 가지 컬러, 다크·라이트 모드, 글자 크기와 불투명도를 조절하세요.
- **구형 기기는 가볍게:** 자동·경량 성능 모드로 화면 갱신 부담을 줄입니다.

### 설치는 간단하게

1. 위 **최신 APK 바로 다운로드**를 누릅니다.
2. 다운로드한 `time-delay-zero.apk` 파일을 엽니다.
3. **설치** 또는 **업데이트**를 누릅니다. 기존 앱은 삭제하지 마세요.

Android 8.0 이상 설치를 지원합니다. 구형 실기기 동작은 추가 확인이 필요하며 일부 Android Go·제조사 제한 기기는 오버레이를 사용할 수 없습니다. iPhone은 지원하지 않습니다. 설치 출처 안내가 나오면 파일과 출처를 확인하고 휴대폰 안내를 따라주세요.

### 업데이트 내용도 앱에서 확인

**☰ 설정 → 앱 업데이트**에서 현재 버전의 변경사항과 새 버전 내역을 확인할 수 있습니다. 공식 배포 주소가 기본 연결되어 있어 별도 입력이 필요 없습니다. 앱을 열 때와 백그라운드에서 약 6시간 간격으로 새 버전을 확인하며, **지금 업데이트 확인**도 지원합니다. 새 버전을 발견하면 상태표시줄과 알림창에 안내하고, 알림을 누르면 변경사항과 다운로드 화면이 열립니다. 다운로드 후 설치 확인은 직접 눌러주세요.

**0.21.0 설치 후 앱을 한 번 열고**, 설정 → 앱 업데이트 → **알림 허용·설정**에서 알림을 허용해주세요. **상태표시줄 테스트 알림 보내기**로 표시와 화면 연결을 확인할 수 있습니다. 이 버전 설치 후 올라오는 새 릴리스부터 백그라운드 알림을 받을 수 있습니다.

즉시 도착하는 푸시가 아닙니다. 절전·네트워크 상태에 따라 확인이 늦어질 수 있으며, 앱을 강제 종료했다면 다시 열어주세요. 실제 기기에서의 알림 표시와 절전 중 실행은 추가 확인이 필요합니다.

### 시간 정확도 안내

HTTP Date와 통신 왕복 시간을 이용한 추정 시각입니다. 응답은 보통 초 단위이며 밀리초는 보간한 표시입니다. CDN·캐시·통신 지연, 실제 예매 처리 서버 차이로 오차가 생길 수 있어 밀리초 정확도나 구매·예매 성공을 보장하지 않습니다. 브라우저의 현재 사이트를 자동 감지하지 않으므로 확인할 사이트를 앱에서 선택해주세요. 알림은 앱 실행 상태와 휴대폰 설정의 영향을 받습니다.
