# 타임딜레이제로

### 기다리는 순간을 보다 정확하게!

## [⬇️ 최신 APK 바로 다운로드](https://github.com/ZERO-hms/time-delay-zero/releases/latest/download/time-delay-zero.apk)

**안드로이드 휴대폰에서 위 링크를 누르세요. GitHub 로그인 없이 다운로드할 수 있습니다.**

### 설치는 간단하게

1. **최신 APK 바로 다운로드**를 누릅니다.
2. 다운로드가 끝나면 `time-delay-zero.apk` 파일을 엽니다.
3. **설치** 또는 **업데이트**를 누릅니다. 기존 앱은 삭제하지 마세요.

Android 9 이상에서 사용할 수 있습니다. iPhone은 지원하지 않습니다. 설치 출처 안내가 나오면 받은 파일과 출처를 확인하고 휴대폰의 안내를 따라주세요. Play 프로텍트 차단이 발생하면 차단 문구와 버전을 알려주세요.

### 다음 업데이트도 편하게

앱에 업데이트 주소가 이미 연결되어 있어 별도 입력이 필요 없습니다. **☰ 설정 → 앱 업데이트 → 지금 업데이트 확인**에서 새 버전을 받을 수 있습니다. 앱을 열 때 자동 확인도 지원합니다(6시간 간격). 다운로드 후 설치 확인은 직접 눌러주세요.

### 이런 기능이 있어요

- 다른 앱 위에 표시하는 이동 가능한 시계
- 네이버 사이트 검색과 즐겨찾기
- 목표시간 및 남은시간 표시
- 알람음·진동·하이라이트 선택
- 여섯 가지 컬러 테마와 다크·라이트 모드

서버 시각은 HTTP Date 기반 추정값입니다. 밀리초 표시가 밀리초 정확도를 의미하지 않습니다. 알림은 휴대폰 설정과 실행 상태의 영향을 받습니다.
